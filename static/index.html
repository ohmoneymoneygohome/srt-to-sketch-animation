FFmpeg 安装提示

      
  1. Windows：安装 FFmpeg，并把 bin 目录加入系统 PATH。
  2. macOS：可使用 Homebrew 安装 FFmpeg。
  3. Linux：使用系统包管理器安装 FFmpeg。
  4. 重新打开终端后运行 ffmpeg -version 与 ffprobe -version 验证。

      
如果已安装但仍显示未找到，先点“重新检测”；若仍未识别，请重启本地工作流服务，让它重新读取系统 PATH。
